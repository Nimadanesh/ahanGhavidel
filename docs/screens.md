### Persian source copy + feature map

**بخش:** چهار گروه اصلی مشتری  
**UI:** تب‌های ۲×۲ + پنل جزئیات (پیش‌فرض: گروه ۱)

#### ۱) بساز‌بفروش (سازنده خرد ۴–۵ طبقه)

| دردسر واقعی | فیچر ما |
| --- | ---- |
| خرید مرحله‌ای طی ۱۸–۲۴ ماه؛ هر بار قیمت‌گیری و چانه‌زنی از صفر | **پروژه من** — پروفایل پروژه + تاریخچه خرید + تخفیف پلکانی وفاداری |
| نمی‌داند چه تناژ و سایزی برای هر مرحله لازم است | **محاسبه‌گر تناژ مرحله‌ای** — متراژ + طبقات ← تفکیک سایز (فونداسیون/ستون/سقف) |
| ترس از جا ماندن از قیمت با نقدینگی محدود | **تسویه آنلاین = قیمت قطعی همان لحظه** + هشدار پیامکی نوسان قیمت (رصد، نه قفل) |
| گم‌شدن فاکتورها و اختلاف حساب | **صورتحساب معین آنلاین** — پیش‌فاکتور، قبض باسکول و سابقه PDF در یک‌جا |

#### ۲) پیمانکار و مجری پروژه (عمرانی و نیمه‌صنعتی)

| دردسر واقعی | فیچر ما |
| --- | ---- |
| نیاز به آنالیز قیمت و پیش‌فاکتور رسمی برای شرکت در مناقصه | **پیش‌فاکتور رسمی فوری** — با مهر و سربرگ، اعتبار تا پایان وقت همان روز (عرف بازار) |
| کسری یا مغایرت وزن هنگام تحویل در کارگاه | **قبض باسکول آنلاین + عکس بار** قبل از حرکت ماشین |
| نقدینگی قفل در پروژه؛ نیاز به خرید مدت‌دار | **خرید اعتباری چکی (صیادی)** — سقف اعتبار بر اساس سابقه خرید در پنل |
| هماهنگی حمل به کارگاه‌های پراکنده وقت‌گیر است | **حمل یکپارچه** — انتخاب باربری، کرایه شفاف، رهگیری راننده |

#### ۳) همکاران شهرستان (بنکداران و آهن‌فروشان شهرهای اطراف)

| دردسر واقعی | فیچر ما |
| --- | ---- |
| برای قیمت کف بناب باید مدام تلفن بزند و به چند نفر اعتماد کند | **پنل همکار** — قیمت اختصاصی همکاری + موجودی لحظه‌ای کارخانه‌های بناب |
| بار می‌خرد اما از بارگیری و رسیدن بار خبر ندارد | **رهگیری سفارش** — وضعیت بارگیری، بارنامه، شماره راننده در اپ |
| تسویه و مغایرت حساب بین‌شهری اعصاب‌خردکن است | **کیف حساب همکار** — واریز آنلاین، مانده لحظه‌ای، خروجی اکسل حسابداری |

#### ۴) تولیدکنندگان مصنوعات (تیرچه‌ساز، خاموت‌زن، سوله‌ساز)

| دردسر واقعی | فیچر ما |
| --- | ---- |
| مصرف مستمر ماهانه اما خرید نامنظم و قیمت‌های متفاوت | **قرارداد خرید دوره‌ای** — تناژ ماهانه با تسویه هر پارت به قیمت روز + اولویت بارگیری |
| سایز خاص (۸ و ۱۰ آجدار) همیشه موجود نیست | **هشدار موجودی** — اعلان پیامکی به‌محض شارژ سایز موردنظر |
| نیاز به خدمات برش/خم که باید جای دیگر ببرد | **سفارش خدمات‌دار** — میلگرد + برش/خم در یک سفارش، تحویل آماده‌مصرف |

## Screen 5 — `spine`

| Field | Value |
| ----- | ----- |
| **Order** | 5 |
| **Route** | `/p/5` |
| **Title** | ستون فقرات اپ / فیچرهای مشترک |
| **Purpose** | Present shared features that form the future app’s spine. |
| **Primary CTA** | Next → export path |
| **Interactive** | None |
| **Status** | content-ready |

### Key messages (EN)

Five shared pillars; **Risk #1:** if price update is hard, product is abandoned in days — simplicity is mandatory for the *future* product (explain only in demo).

### Persian source copy

**عنوان پیشنهادی:** ستون فقرات اپ · فیچرهای مشترک

1. **تابلو قیمت روز** — قیمت میلگرد کارخانه بناب (مثلاً فولاد بناب، شاهین بناب، …) + قیمت دم در مغازه؛ به‌روزرسانی باید به‌سادگی یک پیام تلگرام یا حدود ۳ کلیک باشد  
2. **ماشین‌حساب وزن و قیمت** — جدول وزن استاندارد شاخه (سایز ۸ ≈ ۴٫۷۴ کیلو تا سایز ۳۲)  
3. **هشدار قیمت پیامکی** — وقتی اینترنت قطع است SMS قابل اتکاست  
4. **پنل ادمین ساده** — به‌روز کردن قیمت، دیدن سفارش/رزرو، **لیست تلفن مشتری** (این لیست دارایی واقعی کسب‌وکار است)  
5. **نصب PWA** — بدون استور؛ آخرین قیمت‌های دیده‌شده آفلاین  

**ریسک شماره ۱:** اگر آپدیت قیمت سخت باشد، محصول ظرف چند روز رها می‌شود — سادگی طراحی اجباری است.
